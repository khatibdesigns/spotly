# Spotly — App Store Optimization (ASO) copy

**Positioning rule (important):** Spotly's universal value is **discover kid-friendly places → plan the day with AI → keep the memories**. These work *everywhere*, for free, with no merchant onboarded. **Offers, vouchers and booking only exist at onboarded venues**, so we describe them as *"where available"* — never "book & buy anything." This keeps store reviews honest (over-promising "buy everywhere" → 1-star "there's nothing to buy near me").

Char limits: **iOS** title ≤30, subtitle ≤30, keywords field ≤100 (comma-separated, no spaces), promo text ≤170, description ≤4000. **Android (Play)** title ≤30, short description ≤80, full description ≤4000.

## Review-prompt strategy (the #1 ASO lever)
- Trigger the in-app review request **right after a "wow" moment**, never on cold launch:
  - just after a plan finishes generating, or
  - just after a memory/album is saved.
- Cap to once per user per long window (use the native StoreReview throttling).
- Seed early ratings via the beta/founding families before paid traffic starts.

## Notes
- Keep the title brand-forward (`Spotly`) + 2–3 high-value keywords; don't keyword-stuff the title.
- iOS keywords field: singular/plural and spacing matter — Apple splits on commas; don't waste chars on words already in the title/subtitle.
- Re-test keywords after launch with real impressions-to-installs; iterate monthly.
- Localize screenshots too (Arabic UI captures), not just text.
